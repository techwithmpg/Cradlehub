## External source behavior

- `CRADLE MAINSHEETS` → active Main Branch is **PROVISIONAL** and resolved by existing workbook source configuration. The parser remains branch-agnostic. No SM workbook is configured.
- Reports iterates resolved workbook configurations, reads each selected workbook through the existing reader, and projects each source independently. Adding a later SM workbook requires a source configuration entry with its workbook ID, label, and branch label; the report panels and parser accept multiple source summaries.
- Main scope shows only the mapped source with MASTER SHEET and READ ONLY labels. SM scope reports no source and never reads the Main workbook. All Branches labels the Sheet subset as Main-only; it does not imply company coverage.
- Selected dates filter visit, duty, and review records. The reader's previous and current weekly tabs define an explicit coverage interval. Full, partial, no coverage, and unavailable are distinct. Missing history is not represented as zero.
- Sheet evidence remains independently loaded after canonical Reports. Google auth, metadata, tab read, parse, and adapter timings are already logged by the existing reader; the Reports action logs total Sheet read plus projection elapsed time. No speculative cache was added.
- Sheet service and attendant names remain source text only. There is no automatic service or staff identity link, fuzzy match, or canonical total effect.

## Cash Flow presentation

- The separate Sheet payment panel was removed from the Cash Flow workspace. Canonical `LedgerRecordItem` and `SheetTransactionReference` use a discriminated presentation union within one Ledger table.
- Sheet rows have their own evidence amount column and no canonical transaction ID, financial effect, or mutation menu. Unknown times display `Time unknown`; ambiguous amounts display `Amount unknown`.
- The canonical finance model, drawer calculations, and reconciliation calculations were not changed. The existing Cash Flow read model can show canonical ledger rows from dates outside the selected business date; that pre-existing date-scope issue is outside this presentation correction and needs its own decision before financial totals change.
