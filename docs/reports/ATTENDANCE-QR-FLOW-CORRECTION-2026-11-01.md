## Root cause and corrected workflow

- `/staff/scan` previously waited for GPS readiness before mounting the camera. The camera now opens immediately. Previously granted GPS may prepare in parallel, but the processing page always obtains a new fix after QR decode. The decoded QR is single-shot; the server routing action normalizes its code before Staff navigation.
- `/staff/scan/process/[publicCode]` shows QR recognition, location verification, attendance validation, and the actual result in that order. An attendance Staff camera decode persists a signed, two-minute, user-bound operation grant in the server-only ledger before setting a path-scoped HttpOnly cookie. A Server Action verifies identity and signature, expires the browser cookie, then calls a conditional database RPC bound to token hash, user, code, operation ID, and database-clock expiry. Only the successful claimant proceeds automatically to fresh GPS and normal server attendance authorization. Missing, invalid, expired, mismatched, consumed, unavailable, or stalled claims leave an explicit attendance action. A stalled claim exposes that action after eight seconds; late grants cannot auto-start it.
- `/scan/[publicCode]` is the native-camera/printed-link route. Both direct and Staff processing pages read the active QR point's type server-side on each request. Every attendance QR, including a code with a room-like or legacy prefix, shows “QR code recognized” and one explicit “Record attendance” tap; refresh and history render from the same database classification. Verified room/resource codes continue automatically. Unknown, inactive, invalid, or unavailable classification renders an inert “QR code unavailable” state. The server continues to authorize attendance and service starts.
- A location retry stays on the current page, obtains fresh GPS, and repeats normal server authorization with the same operation ID. The server still enforces freshness, accuracy, branch radius, assignment, device and idempotency controls. No client coordinates or grant can authorize attendance on their own.
